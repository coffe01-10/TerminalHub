Terminal Hub v0.3.0 — Windows x64（2026-10-01 本地迭代）

解压整个文件夹，双击 TerminalHub.exe。无需安装 .NET SDK。
系统要求：Windows 10 1809 或更高版本 / Windows 11，x64。

未安装 PowerShell 7 时，首次启动会让你选择本机可用的 Shell。
可以选择 Windows PowerShell、命令提示符或填写自定义程序路径。
WSL 选项需要已经安装并配置好 Linux 发行版。

Ctrl+Shift+N 新建会话；Ctrl+Tab 切换会话。
Alt+1…9 按左侧顺序切换到对应终端。
点击顶部设置按钮 → 快捷键，可按键录入上一个、下一个及第 1–9 个终端的快捷键。
Backspace / Delete 清除绑定，点击「完成」保存；可恢复默认配置。
快捷键在主窗口内生效，不是系统全局快捷键。
Ctrl+Shift+P 打开命令面板，按名称或目录查找终端，也可执行常用操作。
命令面板使用 ↑ / ↓ 选择、Enter 执行、Esc 返回；快捷键可在设置中修改。
设置 → 工作区可保存多个命名模板，编辑终端目录、Shell、参数及启动命令。
打开模板会新建终端，原有终端继续运行；启动命令仅在手动打开模板并启用时执行。
再次打开程序会激活已有窗口，不会重复创建终端。
Ctrl+点击网址或本地文件路径可打开；应用占用鼠标时使用 Ctrl+Shift+点击。
默认用记事本打开文件；设置 → 关于填写 Code.exe 路径后可定位报错行号。
拖入本地文件插入按 Shell 引用的路径，不自动执行；SSH 会话不接受本地文件路径。
支持 OSC 133 的 Shell 显示命令结果与耗时，PowerShell 集成需要 PSReadLine。
设置 → 关于可开启后台命令完成提醒、查看版本及手动检查更新。
Ctrl+Shift+C 复制选中文本；Ctrl+V 粘贴；Ctrl+C 中断程序。
鼠标拖选；应用启用鼠标协议时按住 Shift 使用本地拖选。
点击分屏并点击窗格，确定当前输入目标。
Claude 输入法组合文字按终端格换行；超出输入框时显示组合光标附近的内容。
改字号或切换窗格后更新输入法位置，失焦或移除视图时清除旧组合文字。
主视图和缩略图复用未变的终端行绘制，减少连续输出时的重复排版。
会话卡显示新输出、进程退出和非零退出码。

关闭应用会结束本次启动的终端进程。
下次打开会恢复会话布局并创建新 Shell，不会恢复旧进程。
配置保存在 %APPDATA%\TerminalHub\settings.json。
