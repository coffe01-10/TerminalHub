# README artwork

**English** · [简体中文](README.md) · [Documentation](../README.md)

The repository introduction follows the v0.4.1 launch film's dark background, blue/teal palette, and pixel wordmark. The film illustrates product interactions. SVG assets provide brand/theme artwork, not application screenshots.

## Current assets

- `hero-en.svg` / `hero-zh.svg`: bilingual banners using the film's three-terminal emblem and pixel wordmark, with “Let AI code. Stay in control.”
- `hero-en-compact.svg` / `hero-zh-compact.svg`: narrow-layout variants.
- `generate_showcase.py` generates all four banners, reusing the emblem/glyphs in `generate_logo.py`. It needs only Python's standard library. SVGs contain no external images/fonts; supporting text uses system fallback fonts.
- `runtime.svg`, `ui.svg`, `platform.svg`, `license.svg`: generated by `generate_badges.py`, describing technology, platforms, and license. They do not represent CI/compatibility results.
- `theme-glass.svg`, `theme-black.svg`, `theme-white.svg`, `theme-paper.svg`: the four theme palette illustrations still used by both READMEs. They can be viewed directly without updating screenshots after UI changes.

## Regenerate

From the repository root:

```powershell
python -B docs/readme/generate_showcase.py
python -B docs/readme/generate_badges.py
```

Text and geometry are in the scripts. English/Chinese and compact banners share drawing logic. Run the badges generator only when their facts change. Inspect fallback fonts, desktop/narrow readability, and image links. Important information is also present in prose or alt text.

## Historical assets

The homepage no longer uses `workflow.svg`, `logo.svg`, `typing.svg`, or the older PNG screenshots; they are retained as historical material and need not track current UI changes.

- `workflow.svg`, generated by `generate_showcase.py`, depicts project start, parallel work, and layout restoration. Restoration creates fresh shell processes.
- `logo.svg` comes from `generate_logo.py`; its emblem/glyphs remain active dependencies of the current banners.
- `typing.svg` comes from `generate_typing.py` and illustrates command typing.
- `workspace.png`, `split.png`, `settings.png`, `black.png` were exported on September 29, 2026 using Avalonia Headless + Skia and Mock PTY. They show native controls of that date, not evidence of current UI or real CLI behavior.

The original layout was informed by the write-visual-readme skill. Final assets, prose, and generators are maintained in this repository.
