# Terminal Hub v0.3.2 — Linux x64

本次发布 Linux x86_64 便携包，包含合并后的 Linux 功能和 Windows 兼容性修复。

- Linux 使用真实 PTY，默认 bash；Bash Shell 集成支持工作目录和命令完成标记。
- 支持分屏、弹出窗口、历史滚动与搜索、Ctrl+滚轮缩放及 Ctrl+Insert 复制。
- 文件浏览、图片预览、拖入／拖出文件，SSH 主机管理和 Thunar 文件夹右键集成。
- 修复慢路径拖拽松手后仍启动、图片解码阻塞界面、迟到预览覆盖新内容，以及目录链接目标导致自复制的问题。
- 保留 Windows 原有默认值、快捷键和操作方式；本次不发布 Windows 安装包，Windows 最新发行仍为 v0.3.1。

下载 `TerminalHub-linux-x64.tar.gz`，解压后运行：

```bash
mkdir -p TerminalHub
tar -xzf TerminalHub-linux-x64.tar.gz -C TerminalHub
cd TerminalHub
chmod +x TerminalHub
./TerminalHub
```

无需安装 .NET SDK；适用于 glibc Linux x86_64，仍需发行版的 .NET 8 系统依赖和图形库。Avalonia 需要 libX11、libICE、libSM 和 fontconfig，详见 [Linux 部署说明](https://docs.avaloniaui.net/docs/deployment/linux)。包内附中文快速入门及许可证。

配置位于 `${XDG_CONFIG_HOME:-$HOME/.config}/terminalhub/settings.json`。升级前正常退出程序，保留个人配置；关闭程序会结束其终端进程，再次打开恢复布局并创建新 Shell。

本次完成 Linux x64 自包含交叉编译和打包。已验证合并代码的 Windows 原生 ConPTY、Grok 颜色输出及相关 Headless 回归；当前发布机器没有 Linux/WSL 环境，本次未重新执行 Linux GUI、真实 Linux PTY、系统输入法和文件管理器拖放实机回归。

复现打包命令：

```bash
bash scripts/publish-linux.sh -p:Version=0.3.2
```
