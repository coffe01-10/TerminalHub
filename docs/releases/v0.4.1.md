# Terminal Hub v0.4.1

2026-10-05 发布维护版，在 v0.4.0 基础上完成插件生态第二轮、SSH 远程深化、AI 会话任务面板、性能第二轮及多项验收还账。

**新功能**

- SSH 远程文件管理深化：SFTP 新建目录、重命名、删除、stat（含 posix-rename），远程文件页提供新建/重命名/删除操作。
- AI 会话任务面板：自动探测 claude/codex/grok/gemini/aider，任务以 CLI 参数启动 `tag=AI` 会话，面板聚合运行中/等待输入/已退出状态并通知。
- 插件第二轮：声明式脚本插件（plugin.json `commands` 注册为工作台命令）、DLL 热重载与可选自动重载、两个新官方插件 TerminalBroadcast（广播输入）与 Snippets（命令片段）。
- 五个官方插件（工作区笔记、屏幕摘录、命令看板、广播输入、命令片段）提供独立 ZIP；解压后经「插件 → 导入插件」安装目录使用。
- 插件离线文档随应用与安装包携带：使用说明 `docs/plugins/index.html`，开发教程提供中英文版本。

**修复与优化**

- 修复导入插件时误删导入目录的问题：导入目录只被读取，移除插件只清理已安装副本与插件配置。
- 修复右边界处的字素/组合字符宽度处理，包含代理对与簇宽越界的绘制与定位问题。
- 修复监控释放路径上的死锁：会话清理不再阻塞持锁的界面线程。
- 修复复制快捷键的选区范围判定与输出面板行为差异。
- 修复录制结束时间戳、分屏聚焦门、Linux Dispose 重入、文件拖出崩溃与焦点劫持、PTY 线程模型、资源竞态、C1 解析、宽字符对、无界队列等审计确认问题。
- 性能第二轮：`PutCluster` 零分配路径、预览会话重绘节流 250ms；同机对照 10 会话全输出 CPU -71%、分配 -76%（详见 `PERFORMANCE.md` 与 artifacts 下测量记录）。

**验收范围**

- 真实 ConPTY 上 Claude Code、PowerShell/PSReadLine 与 Codex 0.158.0 中文编辑通过；系统中文输入法经真实按键注入在单窗格、输入区中部、右边界、分屏窗格及弹出窗口均观察到真实组合与提交，候选条跟随位置经自动几何判定与人工截图审核。
- 真实 OpenSSH Server 端到端验证 SFTP 列目录/上传/下载/增删改查全链路，RemoteFiles 页命令回归通过。
- v0.4.1 九场景桌面性能基线与优化对照留底于 `artifacts/performance/`。
- 未覆盖：多显示器/其他 DPI、Linux 实机、微信输入法独立 profile、Codex 登录后编辑、真 GPU IME 候选窗（VM 为间接显示适配器）、安装包实机安装、真 AI CLI 冒烟（VM 未安装）。

升级时请退出应用后替换程序，正在运行的安装实例不会因新构建自动更新；配置继续保存在 `%APPDATA%\TerminalHub\settings.json`。
