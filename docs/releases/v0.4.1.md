# Terminal Hub v0.4.1

2026-10-04 本地维护版。**当前仅在本地构建，尚未发布到 GitHub Release**；发行上传另待安排。

- 修复导入插件时误删导入目录的问题：导入目录只被读取，移除插件只清理已安装副本与插件配置。
- 修复右边界处的字素/组合字符宽度处理，包含代理对与簇宽越界的绘制与定位问题。
- 修复监控释放路径上的死锁：会话清理不再阻塞持锁的界面线程。
- 修复复制快捷键的选区范围判定与输出面板行为差异。
- 三个官方插件（工作区笔记、屏幕摘录、命令看板）随本维护包提供独立 ZIP；解压后经「插件 → 导入插件」安装目录使用。
- 插件离线文档随应用与安装包携带：使用说明 `docs/plugins/index.html`，开发教程提供中文 `development-tutorial.html` 与英文 `development-tutorial.en.html`。

本地构建产物：Windows x64 便携 ZIP、`TerminalHub-Setup-0.4.1.exe` 安装包（本机 Inno Setup 6.7.3 编译生成，未实际安装验证）及三个官方插件 ZIP。

验收范围以本机实测为准：真实 ConPTY 上 Claude Code、PowerShell/PSReadLine 与 Codex 0.158.0 中文编辑通过；系统中文输入法经真实按键注入在单窗格、输入区中部、右边界、分屏窗格及弹出窗口均观察到真实组合与提交，候选条跟随组合光标的位置经人工截图审核确认——仅限单屏 125% 与验收工具 Software+RedirectionSurface 渲染，默认 GPU 后端候选位置未验收（本机装有微软拼音与微信输入法，具体 profile 未独立核实，两者未分别覆盖），见 [验收记录](../acceptance-v0.4.1-2026-10-04.md)。多显示器/其他 DPI、Linux、安装包实机安装与真实 SFTP 远端未验收。

升级时请退出应用后替换程序，正在运行的安装实例不会因新构建自动更新；配置继续保存在 `%APPDATA%\TerminalHub\settings.json`。
