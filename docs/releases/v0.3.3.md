# Terminal Hub v0.3.3 — Windows & Linux

Windows 和 Linux x64 统一发布，包含 PR #55 合并后的功能与兼容性修复。

## Windows 兼容性

- 保留原有 PowerShell 默认值、面板默认显示状态、自动隐藏坞、工具栏与会话卡片样式。
- 恢复底部坞原有四个入口，移除新增的新建会话和设置入口；顶部原有操作保留。
- 保留 Windows 文件双击及 Enter 的应用内预览行为、原有快捷键、Ctrl+滚轮历史滚动与静默 BEL。
- Windows 的 ConPTY 启动及终端颜色逻辑沿用原实现，兼容 Grok Build 的黑底输出。测试工具继承的 NO_COLOR 环境变量曾影响验证；程序仍尊重用户显式配置。

## 共同修复与 Linux 功能

- 修复图片解码阻塞界面、迟到预览覆盖新内容、慢路径拖拽松手后仍启动，以及目录链接目标导致自复制的问题。
- Linux 保留真实 PTY、默认 bash、Shell 集成、分屏、历史搜索、Ctrl+滚轮缩放、文件拖放与 SSH 管理。
- 修复会话侧栏滚动条隐藏状态在内容变化后被覆盖的问题。

## 下载与升级

- Windows 安装版：`TerminalHub-Setup-0.3.3.exe`。
- Windows 便携包：`TerminalHub-windows-x64-preview.zip`，解压整个文件夹后运行 `app/TerminalHub.exe`。
- Linux x64：`TerminalHub-linux-x64.tar.gz`，解压后运行 `./TerminalHub`，包内可执行权限已设置。

两个平台的包均包含 .NET 运行时，无需安装 SDK。Windows 要求 Windows 10 1809 或更高版本 / Windows 11 x64；程序未签名。Linux 适用于 glibc x86_64 桌面环境，需要发行版的 .NET 8 系统依赖及 libX11、libICE、libSM、fontconfig，详见 [Avalonia Linux 部署说明](https://docs.avaloniaui.net/docs/deployment/linux)及 [.NET Linux 系统依赖](https://learn.microsoft.com/dotnet/core/install/linux)。ARM64 和 Alpine/musl 不在本次发行范围。

升级前正常退出 Terminal Hub；退出会结束它启动的终端进程。保留个人配置，重新启动会恢复布局并创建新 Shell。发布包不包含个人设置和 SSH 记录。Linux v0.3.2 发行继续保留。

## 验证范围

合并前已完成 Windows 真实 ConPTY 中文输入与编辑、Grok 颜色输出，以及相关 Avalonia Headless 回归。本次重新构建 Debug、Release 和两个平台的自包含发布产物，核对 Windows 版本、包内容及 Linux ELF 架构与执行权限。

当前发布机器没有 Linux/WSL 环境，本次未重新执行 Linux GUI、真实 Linux PTY、系统输入法及文件管理器拖放实机验证；Windows 安装器生成后未自动安装到用户系统。

复现打包：

```powershell
pwsh -File scripts/publish-windows.ps1
```

```bash
bash scripts/publish-linux.sh
```
