# Terminal Hub v0.1.0

Terminal Hub 首个公开版本：基于 Avalonia 和 .NET 8 的原生多会话终端，本次提供 Windows x64 便携包。

## 下载与启动

下载 `TerminalHub-windows-x64-preview.zip`，解压后打开 `win-x64` 文件夹，双击 `TerminalHub.exe`。无需安装 .NET SDK。

支持 Windows 10 1809 及以上版本、Windows 11，x64。未安装 PowerShell 7 时，可在启动界面选择 Windows PowerShell、命令提示符或自定义 Shell。

## 初版能力

- Windows ConPTY 终端、多会话缩略图、分屏、独立窗口、主题与字号调整。
- 中文输入法与应用编辑光标定位；调整窗口宽度时重排普通终端文本。
- 鼠标选中、跨行复制、终端历史搜索及匹配高亮。
- 工作区布局恢复，保留会话顺序、名称、目录和 Shell；重新启动会创建新进程。
- 会话后台新输出提示、运行状态与退出码。
- 文件、日志、进程监控与 SSH 面板。

常用快捷键：`Ctrl+Shift+N` 新建会话、`Ctrl+Tab` 切换、`Ctrl+Shift+C` 复制、`Ctrl+V` 粘贴、`Ctrl+C` 中断。

## 本次验证

- 相关终端缓冲、输入、输入法、历史、布局、工作区和会话状态回归通过。
- 回放及真实 Windows ConPTY 下验证 Claude Code 中文编辑、方向键跨中文、换行和窗口缩窄。
- Windows 自包含发布成功；已实际打开发布版主窗口，确认 PowerShell 会话显示。

## 已知范围

- Unicode 字素簇、部分 emoji 和组合字符仍待完善。
- 系统输入法候选窗、多显示器场景，以及 Grok/Codex 登录后的完整交互尚未完成实机验证。
- 尚未进行有数据支撑的多会话性能优化。
- 本次只提供 Windows x64 发布包；Linux 源码有 PTY 实现，本轮未验证 Linux 发布版。
- 程序未签名。关闭应用会结束终端进程，工作区恢复不会恢复旧进程。
- 应用当前使用单实例机制，重复启动不会自动将已有窗口切到前台。
