# Terminal Hub v0.3.0

本版把项目启动、会话查找与后台任务状态串成日常工作流程，保留左侧缩略图原有风格。

顶部查找、输出与工具按钮统一内容对齐；查找结果的长名称省略、快捷键靠右，选中背景跟随主题。关于页面支持滚动，避免较矮窗口截断更新操作。

## 新功能

- **命令面板**：顶部「查找」或 `Ctrl+Shift+P` 打开。按会话名、目录和操作查找，支持方向键、Enter、Escape；展示已有快捷键，面板输入不会发送到 Shell。设置中可修改面板快捷键。
- **命名工作区模板**：设置 → 工作区保存当前名称、目录、Shell、参数、会话顺序与分屏。支持重命名、修改配置、更新当前布局、删除及打开；命令面板也能打开模板。打开时创建新进程，其他终端继续运行。
- **模板启动命令**：每个本地 Shell 可单独设置命令与执行开关；只在手动打开模板且启用时运行。正常启动恢复上次布局不会自动重跑命令，SSH 不自动发送启动命令。
- **再次启动激活原窗口**：第二次启动传递激活请求，恢复最小化窗口并带到前台，不重复创建 Shell；早于窗口初始化的请求会在窗口就绪后处理。
- **命令状态与提醒**：支持 OSC 133 的 Shell 提供运行、结束、退出码及耗时。PowerShell 会话接入 PSReadLine；设置 → 关于可开启后台命令完成／失败提醒，同一提示位置合并更新，不根据输出中的 `error` 单词判定失败。
- **终端内容操作**：Ctrl+点击普通网址、OSC 8 超链接和报错中的本地文件路径；鼠标由 TUI 接管时用 Ctrl+Shift+点击。相对路径以对应会话目录为准。默认用记事本打开文件，设置 Code.exe 后支持行号定位，避免点击脚本文件就直接执行它。
- **拖入文件**：本地会话插入按 PowerShell、cmd、bash 或 WSL 引用的文件路径，支持含空格及多个文件，不自动执行。SSH 不把远程路径映射为同名本地文件，也不接收本地文件拖入。
- **关于与更新**：显示当前版本、当前版本说明与 GitHub 发布入口，手动检查最新正式版本，提供新版下载入口；不自动结束或替换运行中的终端。
- **Windows 安装包**：同时提供安装版与便携 ZIP。安装程序沿用应用标识、保留用户配置，不再自动 taskkill 正在运行的终端；安装前由用户正常关闭应用。

## 验证与范围

相关终端解析、输入、输入法、历史、快捷键、布局、主题、分屏、弹出窗口及新功能回归通过。真实 PowerShell / ConPTY 验证了命令成功、原生命令非零退出码、失败后的下一条成功命令，以及 PowerShell 错误结果。检查了 1100×680 和 1440×900 下的模板与命令面板 Headless 渲染。

原生桌面确认主窗口已显示；再次启动后主进程及五个 Shell 进程保持不变。旧版 PowerShell 启动参数迁移、拖入路径不执行命令也有对应回归。Windows 自包含便携 ZIP 与安装程序均已构建，安装包内容及中文名称已检查；尚未执行系统安装、覆盖升级或卸载验证，GitHub 发布仍待本轮授权。

命令提醒在应用内显示，尚未接入 Windows 系统通知。没有提供完成协议的 Shell 仍使用输出与进程状态。普通文字网址／路径识别以当前物理行为范围，OSC 8 链接可跨格保留；默认记事本不定位行号，行号定位需要配置 VS Code。未知自定义 Shell 的文件引用规则未实机验证。

多会话性能测量与优化继续暂缓。系统输入法候选窗、多显示器、所有自定义 Shell 与编辑器组合尚未全面实机验证。程序未签名。

## 使用

Windows x64 用户可运行 `TerminalHub-Setup-0.3.0.exe`，或解压整个 `TerminalHub-windows-x64-preview.zip`，进入 `win-x64` 双击 `TerminalHub.exe`。无需安装 .NET SDK。配置仍位于 `%APPDATA%\TerminalHub\settings.json`。
