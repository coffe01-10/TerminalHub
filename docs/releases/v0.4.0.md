# Terminal Hub v0.4.0

2026-10-03 已发布 [GitHub Release](https://github.com/coffe01-10/TerminalHub/releases/tag/v0.4.0)，提供 Windows x64 便携包、Linux x64 包和插件 SDK。

- 会话跨工作区拖动，悬停标签切换工作区；保留原进程、输出与属性。
- 任意窗格继续左右/上下拆分，支持嵌套布局、边缘拖放、比例调整、最大化、移除视图；布局树进入工作区保存、模板与撤销/重做。
- 可配置的最近使用终端切换器，覆盖多个工作区和弹出会话。
- 本地 .NET/Avalonia 插件机制、公开 SDK、界面扩展位置、模块管理、命令/快捷键及事件接口，附三个独立示例。
- 中英文及跟随系统语言设置，即时刷新工作台文案，保留终端原始输出和用户数据。
- 布局撤销/重做涵盖分屏、比例、交换及跨工作区迁移；关闭进程和 Shell 操作不进入历史。
- 工作区工具恢复独立窗口与左侧导航，关闭再打开保留页面和编辑状态；插件管理、分屏标题、会话概览与最近终端切换器经过界面精修。

旧工作区配置继续兼容；恢复布局创建新的 Shell 进程。插件、工作区、快捷键及主题配置仍在用户配置目录保存。升级时请退出应用后替换程序，正在运行的安装实例不会因新构建自动更新。

已补做相关回归及真实 Windows 原生窗口/ConPTY 验收：六窗格、布局操作、工具状态与插件并行启停通过。修复备用终端填补、自动隐藏侧栏拖放落点和工具页面样式。系统输入法实际候选窗、多显示器、Linux 和真实 SFTP 远端未验收；Windows 安装包因缺少 Inno Setup 未生成。

工具窗口恢复及界面精修的验收见 [本轮记录](../ui-refinement-2026-10-03.md)。
