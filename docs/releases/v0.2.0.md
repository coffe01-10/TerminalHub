# Terminal Hub v0.2.0

本版整理主界面与设置，新增自定义终端切换快捷键，保留左侧终端缩略图原有风格。

## 新功能

- 设置分为外观、工作区、快捷键和启动四个分类。主题、字体与字号集中在外观首屏，提供实时文字预览、字号调整和重置。
- 自定义上一个、下一个，以及按侧栏顺序直达第 1–9 个终端的快捷键。点击输入框后按键录入，Backspace / Delete 清除，点击「完成」保存，可恢复默认。
- 默认 `Ctrl+Tab` / `Ctrl+Shift+Tab` 循环切换，`Alt+1…9` 直达终端。快捷键在主窗口内生效，不是系统全局快捷键。
- 重复绑定、占用普通输入或与复制／粘贴等现有操作冲突时显示原因，错误绑定不生效。录入按键不会切换会话或发送到终端。

## 界面调整

- 顶部与终端工具栏使用统一矢量图标和按钮状态，活动会话显示真实运行状态及退出码。
- Dock 移除重复的新建和设置入口，保留监控、SSH、日志与打包工具；自动隐藏时，底部「工具」提示可呼出 Dock。
- 纸张主题减轻背景纹理与主面板阴影，提高状态文字、边框和强调色的对比度。左侧缩略图的尺寸、透视、叠层和排序交互保持原有设计。
- 主终端切换动画缩短到 300ms，Dock 展开缩短到 180ms，保留快速切换时连续衔接的行为。
- 保留原应用图标，主窗口与弹出窗口打开后重新应用图标，触发 Windows 任务栏刷新。

## 验证与范围

构建成功；相关布局、主题、分屏、输入法、键盘、弹出窗口和快捷键回归通过。检查了四主题的 Avalonia Headless 渲染、设置及快捷键界面。

任务栏刷新后的实际图标显示仍待实机核对。本版未进行多会话性能测量或优化；系统输入法候选窗、多显示器，以及 Grok/Codex 登录后的完整交互仍未全面验证。程序未签名。

## 下载

下载 `TerminalHub-windows-x64-preview.zip`，解压整个文件夹后进入 `win-x64`，双击 `TerminalHub.exe`。支持 Windows 10 1809 及以上版本或 Windows 11，x64，无需安装 .NET SDK。
