# Terminal Hub v0.3.4 — Windows & Linux

面向 AI CLI 的原生终端工作台。本版汇总 v0.3.3 之后的工作区、工具、界面与终端编辑改进。

## 工作区切换与排序

- 修复快速连续点击工作区触发重命名弹窗、阻挡后续切换的问题；重命名移至标签右键菜单。
- 工作区标签支持左右拖动排序、标签让位预览及边缘自动滚动，顺序随配置保存。Esc 或拖出标签栏松开可取消。
- 合并会话及缩略图列表更新、复用缩略图并减少重复布局，工作区切换直接呈现目标终端，保留后台进程和输入焦点。
- 同机 20 个真实 PowerShell ConPTY 持续输出测量：固定侧栏切换加布局平均耗时 601.81 → 128.81 ms，收起侧栏 446.96 → 55.27 ms。此结果不代表 GPU 帧率或稳定 60 FPS。

## 新功能与体验

- 多工作区各自保存会话、活动终端及分屏布局；支持左右、上下、四窗格和最大化当前窗格。
- 自动收起的会话侧栏靠近左侧呼出，当前终端居中，远离中心的缩略图逐渐淡出；固定侧栏沿用原有行为。
- 工作区工具增加输出规则与命中定位、广播输入、项目任务、SSH 远程文件及终端录制回放，重新整理导航、表单和空状态。
- 跨会话搜索可跳转到所属工作区；更新页面提供按平台下载、进度和取消。
- 改进 Claude / Codex 光标和选区兼容、终端编辑与主题显示；统一按钮、浮层及活动窗格样式。
- README 改为 AI CLI 工作台定位及 SVG 产品叙事，保留原有主题风格 SVG。

## 下载与升级

- Windows 安装版：`TerminalHub-Setup-0.3.4.exe`。
- Windows 便携版：`TerminalHub-windows-x64-preview.zip`，解压后运行 `app/TerminalHub.exe`。
- Linux x64：`TerminalHub-linux-x64.tar.gz`，解压后运行 `./TerminalHub`。

发布包包含 .NET 运行时，不需要安装 SDK。Windows 要求 Windows 10 1809 或更高版本 / Windows 11 x64。Linux 适用于 glibc x86_64 桌面环境，需要 libX11、libICE、libSM、fontconfig 及发行版的 .NET 8 系统依赖，见包内快速开始说明。

升级前自行保存任务并正常退出旧版；退出会结束其终端进程，再次启动会恢复布局并创建新 Shell。发布包仅包含程序与发行文档，不包含个人设置和 SSH 记录。

## 验证范围

工作区快速连点、拖动排序、取消、重命名、边缘滚动、持久化及既有工作区／侧栏／分屏相关 30 项 Headless 回归通过。工作区切换优化另有同机真实 Windows 桌面与 ConPTY 前后测量，详见 [测量报告](https://github.com/coffe01-10/TerminalHub/blob/main/docs/performance-workspace-switch-2026-10-02.md)。其他功能的协议、回放及实机验证范围记录于仓库对应开发文档。

本次重新构建两个平台的自包含发行包及 Windows 安装器。未进行 Linux 实机、真实 SSH 服务器、系统输入法候选窗或安装器覆盖升级验证。
