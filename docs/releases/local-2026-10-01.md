# Terminal Hub 本地迭代包（2026-10-01）

本地包包含已实现的工作区分组、命令记录及输出工具，并补齐本轮 Claude 输入法与绘制优化。程序集版本仍为 0.3.0；没有创建、推送或更新 GitHub Release。

- Claude 长组合文字不再在输入框下沿截断：按完整字符簇换行，在输入区内滚动到组合光标。绘制和候选窗共用位置及输入区信息，不覆盖下分隔线和状态栏。
- 字号、网格尺寸及窗格位置变化时通知输入法更新位置。切换会话、窗格失焦或视图移除后清除旧组合文字。组合文字覆盖格使用背景遮住原有文字，避免两层字形重叠。
- 主终端与缩略图复用相同终端行的绘制；快速切换先显示首帧，再建立行缓存。主题或字号改变后重建绘制，缓存最多两屏行，不保存整个历史。
- Grok Build 黑底使用可读的会话默认文字，界面仍可保持纸张主题；单元格背景不再漏出行间细线。「… → 终端配色」可手动选择并随工作区保存。终端区域的通用 Ctrl+点击悬浮提示已移除，打开链接和拖入文件仍可用。
- 左侧缩略图悬停时轻轻抬起并展开倾角，离开平滑收回，按下略微回压；点击展开从当前卡片画面位置开始。动画保持鼠标命中区域和终端网格不变。
- [性能记录](../performance-2026-10-01.md)包含同机 1／5／10 会话的固定负载对比及内存代价。10 会话全部输出的 Headless 处理耗时下降约 62%，不能据此承诺桌面 CPU 降幅。

本地文件：`app/TerminalHub.exe`、`artifacts/TerminalHub-windows-x64-preview.zip`、`artifacts/installer/TerminalHub-Setup-0.3.0.exe`。便携 ZIP 解压整个 `app` 文件夹后启动。

源码回归与真实 Claude ConPTY 编辑用于验证位置计算、中文方向键、缩放及多行粘贴。系统输入法实际候选窗、多显示器和系统安装／升级尚未验证。没有自动关闭用户运行中的终端或安装程序。
