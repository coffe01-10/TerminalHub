# Terminal Hub v0.3.1

本版改善 Claude 中文输入、Grok Build 配色、多会话绘制和左侧缩略图交互。

- **会话与输出工具**：增加会话分组和置顶、命令记录与输出定位、命令收藏和输出书签；完善工作区模板预览、编辑和导入导出。侧栏显示新输出、进程退出和非零退出码。
- **Claude 输入体验**：长输入法组合文字按终端格换行，并在输入区内显示组合光标附近的内容；绘制与候选窗共享定位。字号、网格或窗格变化时更新输入法位置，失焦或切换时清除旧组合。
- **Grok 与浅色主题兼容**：自动识别大面积应用背景，为 Grok 黑底选择可读的默认文字、光标和选区，外层仍可保持纸张主题。修复单元格之间漏底的细线。「… → 终端配色」可选择自动、跟随界面、深色、浅色，设置随工作区保存。
- **缩略图动画**：悬停时轻轻抬起并展开倾角，离开平滑收回，按下略微回压。点击展开从当前卡片画面衔接，固定命中区域避免边缘抖动。
- **绘制优化**：复用未变终端行的绘制，减少主视图和缩略图重复排版。同机固定负载的 10 会话 Headless 处理耗时中位数由 2522.1 降至 958.8 ms；工作集有所增加，这不是桌面 CPU 或帧率测量。详见仓库中的性能记录。
- **界面整理**：移除终端区域的通用 Ctrl+点击悬浮提示，打开链接和拖入文件的操作保持可用。

验证包括相关终端、输入法、绘制、主题、布局与工作区回归，以及真实 Claude ConPTY 编辑、Grok 启动输出捕获和回放。Grok 没有提交模型请求。系统输入法实际候选窗、多显示器、安装／覆盖升级及桌面动画帧率尚未验证；程序未签名。

Windows x64 用户可下载 `TerminalHub-Setup-0.3.1.exe`，或解压整个 `TerminalHub-windows-x64-preview.zip`，进入 `app` 文件夹运行 `TerminalHub.exe`。无需安装 .NET SDK。

升级前请正常关闭 Terminal Hub，并先处理运行中的任务；关闭应用会结束其终端进程。配置继续保存在 `%APPDATA%\TerminalHub\settings.json`，再次打开会恢复布局并创建新 Shell。
