# 工作区工具恢复与新增模块界面精修

2026-10-03，按用户最新要求恢复原来的独立工具窗口。

## 当前行为

- 点击“工作区工具”打开独立窗口，再次点击激活已有窗口。左侧继续显示输出规则、广播输入、项目任务、远程文件、录制回放及启用的插件工具。主终端尺寸不受影响。
- `ProjectToolsView` 与页面继续缓存。关闭再打开保留所选模块、规则/任务编辑、结果和插件配置；工作区切换更新上下文，关闭与退出保存配置。
- 插件管理使用独立的主题窗口，区分插件、模块与设置页。插件卡片显示版本、状态和错误；模块显示来源，显隐、工作区范围与排序对齐。编辑排序时保存不再重建输入框，避免焦点丢失。
- 分屏标题栏保留最大化和更多菜单，拆分、移除视图与关闭会话仍可从菜单操作；窄窗格优先保留终端名称空间。
- 会话概览使用撑满页面的卡片，显示工作区名称、目录和运行状态；紧凑侧栏同步活动会话。最近终端切换器使用更紧凑的预览、主题背景和选中状态。
- 四种主题的颜色、按钮、复选框、空状态与英文换行统一调整。插件 SVG 导航图标继续支持内联与文件形式。

## 验收发现与修复

- 工具导航重复装配时，Avalonia 虚拟列表的滚动锚点可能指向已经移走的控件，触发 `An anchor control must be a visual descendent of the ScrollContentPresenter`。模块导航是短菜单，改用普通 StackPanel；规则、文件与搜索结果列表继续使用原来的列表实现。
- 广播与远程文件页少定义一行，列表与底部操作/状态区重叠。补齐各自的四行布局。
- 会话概览按钮默认不横向伸展，卡片只占半个页面；英文导航说明被裁切。分别改为撑满宽度与自动换行。
- 插件管理刷新时，配置控件仍属于旧卡片，重复挂载会出错；刷新前先从旧容器解除，再复用控件。排序输入采用原位保存，保留编辑器。
