## v0.3.0：打开项目与切换终端

### 1. 命令面板与终端快速查找

- [x] 新增命令面板入口与可配置快捷键；建议默认 `Ctrl+Shift+P`。
- [x] 按会话名称、工作目录搜索终端，显示足以区分同名会话的信息。
- [x] 用方向键选择、Enter 执行、Escape 关闭；关闭后恢复原输入焦点。
- [x] 收录切换会话、新建终端、分屏、重命名、打开设置等现有操作，展示对应快捷键。
- [x] 面板中的输入与按键由面板处理，不发送到 Shell。

完成场景：打开超过九个终端后，输入项目目录名即可找到目标；选中后切换到它，并能继续输入命令。

### 2. 多个命名工作区与启动模板

- [x] 把当前布局保存为命名模板，支持查看、重命名、更新和删除模板。
- [x] 保存会话名称、目录、Shell、参数、顺序、分屏及活动窗格，复用现有工作区配置。
- [x] 提供工作区列表与打开入口，并纳入命令面板。
- [x] 可为模板中的会话配置启动命令，独立设置打开时是否执行。
- [x] 打开模板时创建新的 Shell 进程，不自动结束其他已运行的会话。
- [x] 保留现有配置与恢复上次布局的行为，使 v0.2.0 用户升级后仍能使用原设置。

完成场景：分别保存“前端项目”和“后端项目”；重启应用后，选择模板即可打开对应目录、终端和分屏。模板启动命令仅按用户保存的执行设置运行。

### 3. 再次启动时激活已有窗口

- [x] 将第二次启动请求传递给已运行的实例。
- [x] 已有主窗口正常显示时将其带到前台；最小化时恢复窗口。
- [x] 保留原会话、输入内容和布局，不创建重复的 Shell 进程。

完成场景：应用已运行时，再次双击 EXE，原主窗口出现并可继续操作。

背景：当前单实例逻辑让第二次启动直接退出，用户容易以为程序没打开。此前受限环境启动导致窗口未显示到用户桌面，是另一项环境问题，应分别判断。

## v0.3.0：任务状态与内容操作

### 4. 后台终端活动提示

- [x] 在原有缩略图上增加轻量的“有新输出”标记，查看对应会话后清除。
- [x] 显示进程已退出的状态与退出码，区分“有输出”和“进程退出”。
- [x] 接入支持的 Shell 的命令开始／完成信息，记录单条命令的运行状态、耗时和退出码。
- [x] 提供可选的后台命令完成／失败提醒；持续输出合并提示，避免频繁打扰。

完成场景：在一个终端运行构建、切到另一个终端继续工作，仍能看到前者有新输出或任务完成；返回查看后活动标记清除。

范围：Shell 进程退出与其中一条命令完成是不同事件。只有收到明确的完成信息才显示命令结果；不以输出里出现 `error` 等词判定整个任务失败。不支持的 Shell 先提供输出与进程状态。

### 5. 终端内容直接操作

- [x] 识别普通网址与终端超链接，提供明确的点击打开操作。
- [x] 识别报错中的本地文件路径及可用的行号，支持打开文件；相对路径基于对应会话目录解析。
- [x] 区分本地路径与 SSH 等远程会话中的路径，避免打开同名本地文件。
- [x] 拖入文件／文件夹时插入路径，按当前 Shell 处理空格、引号及多个文件。
- [x] 保持拖选复制行为；拖入路径只填入输入内容，不自动执行命令。

完成场景：打开输出中的网址或报错文件；把含空格的 Windows 路径拖入 PowerShell，得到可直接使用的路径文本。

完成场景：前端、后端和测试终端分别归组；折叠不常用项目后，仍能看到后台活动提示并快速找到常用终端。

### 2. 命令记录与输出定位（优先）

- [ ] 基于现有命令开始／完成协议记录最近命令、工作目录、耗时和退出码。

完成场景：搜索“启动开发服务”即可填入收藏命令，检查当前目录后按 Enter 执行。
