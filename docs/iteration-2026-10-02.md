## 使用入口

- **自由分屏**：原分屏按钮仍可切换左右双窗格；右键分屏按钮或打开“会话操作”菜单，可选左右、上下、四窗格、最大化 / 恢复当前窗格及回到单窗格。命令面板也能搜索上下、四窗格和最大化。拖动中间分隔条调整比例，布局、两方向比例、四个会话及活动窗格会随工作区和模板保存。最大化为临时显示状态。切换布局复用原进程，会话不足时才新建；关闭窗格会话时优先补入未显示的会话，不足四个时退回双窗格。
- **跨会话搜索**：`Ctrl+Shift+F` 打开搜索，在“当前会话 / 全部会话”中选择范围。结果显示会话名、行号和匹配内容，点击定位；Enter / Shift+Enter 或前后按钮按结果导航。每个会话最多显示 200 条匹配行，包含弹出窗口中的会话；定位弹出会话时收回该窗口并保留进程。使用缓冲锚点处理重排；裁剪、覆盖、主备用屏幕切换或会话关闭后显示原因，不跳到同一行号的新内容。
- **按平台下载**：设置 → 关于 → 检查更新。Windows 提供安装版和便携版，Linux 提供 x64 包，显示新版发行说明。选择保存位置后流式下载，显示字节进度并可取消；完成后可打开文件或目录。下载中断删除本次临时文件，成功前不替换已有目标文件。下载和升级均由用户主动选择，下载不会关闭终端。
- **按钮与浮层**：主工具栏、新建会话、设置、底部坞及通用按钮统一文字居中与圆角，按压呈现轻微横向舒展、纵向压缩和回弹。动画作用于按钮模板的绘制表面，点击范围与命令执行不等待动画。快速反向操作保留当前形变与速度；菜单从依附的触发入口展开，设置面板展开 / 收起支持中途反向，收起时立即让出输入。
- **视觉分层**：四套主题增加面板、卡片和浮层独立颜色；菜单和提示使用浮层颜色，弹窗使用浮层阴影，活动窗格有清晰边框，选中按钮使用主题强调背景。输出 / 工具页签选中背景显式使用主题色，修正纸张主题仍使用 Fluent 蓝色的情况。终端调色板沿用原逻辑，保持窗口、侧栏与底部坞的原有入口和层级。

## 验证与具体问题

新增回归覆盖四窗格实际尺寸、最大化恢复后的模拟器尺寸、比例与模板导入恢复、关闭当前窗格后的会话替补、跨会话搜索重排及裁剪 / 关闭提示、流式下载进度与中断清理、快速连点立即执行、四主题分层与面板展开反向衔接。原有分屏、模板、输入法、终端缓冲、选区、弹出窗口及主题回归已运行；Release 编译通过。扩展回归中 205 项通过，1 项旧注册表测试受沙箱权限限制、1 项可选 Codex 编辑测试未启用；新增的覆盖与弹出会话定位用例及最终主题收尾随后单独通过。

跨会话点击曾出现“视图已切到目标窗格、活动会话属性仍是旧会话”的问题：定位调度先于已有会话同步回调。定位现在排在这些回调之后，并在布局更新后重新核对目标缓冲与锚点。回归保留了该操作顺序。会话状态同步时也避免把程序更新侧栏选中项误当作用户重新分配窗格。

四套主题的四窗格画面使用 Avalonia Headless + Skia 渲染并逐一检查；临时截图用后已删除。原生桌面 + ConPTY 负载另有 [性能测量记录](performance-2026-10-02.md)。没有用网页或浏览器代替原生验证。
