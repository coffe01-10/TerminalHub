# 工作区工具使用说明

本轮增加工作区标签页、输出规则、广播输入、项目任务、SSH 远程文件、终端录制回放。功能已接入原生 Avalonia 主程序。

## 打开新版程序

先保存正在运行的任务并自行退出旧实例，然后在仓库根目录运行：

```powershell
dotnet run --project src/TerminalHub.App
```

应用有单实例逻辑，旧实例仍在运行时，新启动命令会唤起旧窗口。源码和编译产物更新不代表安装版已经更新。

## 工作区标签页

主窗口顶部第二行显示工作区。点击「新建工作区」建立新工作区；点击标签切换；双击名称重命名。标签内的数字表示会话数量，当前工作区使用主题强调色。每个工作区保留自己的会话顺序、活动会话、分屏布局、侧栏固定或收起方式。切换工作区保留后台进程。

标签旁的「×」会关闭该工作区及其中的终端。应用退出后再次启动，会按保存的工作区恢复布局并创建新进程，不能恢复原进程的内存状态。跨会话搜索、任务查看及输出通知可以返回所属工作区。

## 工作区工具

点击顶部右侧「工作区工具」。左侧导航切换五个工具页面，右侧按列表、编辑和结果分区显示。没有规则或任务时，点击空状态中的创建按钮即可开始。规则和任务可用右下角「保存更改」保存，关闭工具窗口也会保存。布局适配四种主题，窗口缩小时表单滚动、操作按钮换行。

| 页面 | 用法 |
| --- | --- |
| 输出规则 | 新增规则，填写关键字或正则、颜色，选择是否通知。屏幕显示高亮；新输出行累计命中次数。点击扫描查询当前工作区的屏幕与历史记录，双击结果跳转。最多展示 200 个定位结果，计数包含全部扫描命中。规则用于所有工作区。 |
| 广播输入 | 勾选至少两个运行中的终端，再点击开启。在该工作区的终端键入、粘贴或拖入路径会发给所选目标；主窗口持续显示目标。点击停止、按 Esc 或切换工作区结束广播。每个目标按自己的括号粘贴模式接收文本，任务面板执行命令不经过广播。 |
| 项目任务 | 新增任务，填写名称、命令并选择目标 PowerShell / Bash 终端。运行或重跑在指定终端执行；停止发送 Ctrl+C，并等待实际完成事件。状态显示退出码及耗时；查看终端跳回对应会话。任务定义按工作区保存。 |
| 远程文件 | 选择 SSH 页保存的主机，打开远程目录，双击目录进入，也可返回上级。上传、下载显示字节进度，支持取消。可在该远程目录打开 SSH 终端。 |
| 录制回放 | 选择录制文件位置开始录制当前终端，停止后保存为 `.threc`。打开录制会创建独立只读播放器，支持暂停、0.5 / 1 / 2 / 4 倍速和时间轴跳转。 |

任务完成使用 Shell 的 OSC 133 完成事件和实际退出码。Windows PowerShell 无法加载 PSReadLine 时，任务会补上命令开始标记，仍由现有提示符返回完成状态；不会修改系统执行策略。自定义 Shell 参数绕过 Shell 集成时，不能保证收到任务完成事件。

## 远程文件的认证与传输

文件管理使用本机 `ssh` 的 SFTP 子系统，沿用 OpenSSH 配置、密钥和 ssh-agent。首次连接需先在普通 SSH 终端完成主机确认。文件传输使用非交互认证，不能在文件面板输入密码。该实现不读取或复制密钥内容，不修改主机确认策略。

下载先写本地临时文件，完成后替换选定文件；上传先写远端临时文件，完成后重命名。如果服务器没有 OpenSSH 的覆盖重命名扩展，覆盖已有远端文件可能被拒绝，原文件会保留。失败或取消会尝试清理临时文件；连接中断无法确认清理时，界面列出远端临时路径。

录制包含开始时的屏幕、随后收到的原始输出、时间和终端尺寸变化；开始前的历史滚动内容不包含在文件里。录制可能含终端显示的敏感信息，由用户选择保存位置，不自动上传。

## 验证范围

新增回归覆盖工作区进程保留与分屏隔离、后台搜索跳转、保存后恢复、新进程重建、重建侧栏时保存不会覆盖分屏、晚到后台的会话也能保存、广播目标与括号粘贴、规则匹配及定位、任务实际完成状态、播放器暂停与跳转、中文与 emoji、UTF-8 中途开始录制、行末换行状态、颜色与尺寸事件、备用屏幕退出后的主屏幕恢复及关闭窗口时完整保存录制。

SFTP 使用内存中的协议对端验证真实二进制报文、中文及带空格和引号的文件名、上传下载、进度、取消和失败后的原文件保留与临时文件清理。四种主题的原生 Headless 界面已检查，临时截图已清理。

本机 Windows PowerShell 与 PowerShell 7 的真实 ConPTY 任务已返回退出码 7，生成的录制回放保留实际输出与完成记录。未连接真实 SSH 服务器，也未进行 Linux 实机验证；不将协议模拟验证描述为真实远程连接通过。

